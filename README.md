# LuxuryStay 🏨

LuxuryStay is a modern hotel and accommodation booking platform designed to provide users with an easy way to discover properties, view accommodation details, and manage bookings.

## ✨ Features

* User registration and login
* Browse accommodation properties
* View detailed property information
* Property pricing and availability
* Hotel/accommodation booking
* Booking management
* Hotel owner/property management
* Admin dashboard
* Database-driven functionality
* Responsive and user-friendly interface

## 🛠️ Technologies Used

* HTML5
* CSS3
* JavaScript
* PHP
* MySQL
